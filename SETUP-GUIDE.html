1 · The one place you edit — the Settings block

Open index.html in any text editor (Notepad, VS Code, or even directly on GitHub). Near the very bottom, inside the <script>, you'll see this block. This is the only thing you edit. Paste your IDs between the quotes and save. Leave any value empty ("") to keep that tool off.

var ATC = {
  supabaseUrl:  "https://jenpcqosofarxmthwouq.supabase.co",   // ✅ already set
  supabaseKey:  "sb_publishable_...",                         // ✅ already set
  calendly:     "",   // e.g. "https://calendly.com/yourname/30min"
  metaPixelId:  "",   // e.g. "1234567890123456"
  ga4Id:        "",   // e.g. "G-XXXXXXXXXX"
  clarityId:    "",   // e.g. "abcd123xyz"
  gtmId:        "",   // e.g. "GTM-XXXXXXX"
  whatsapp:     "",   // e.g. "923001234567"  (country code, no + or spaces)
  notifyEmail:  "hello@adsthatconvert.co",
  web3formsKey: ""    // FREE instant email alert on every lead (web3forms.com)
};
That's the whole idea: no messy pasting of script tags in different places. You put the ID in here once, and the site loads the correct code automatically.

2 · Put the site live (your plan is correct 👍)

Your order — Hostinger domain → GitHub → Vercel → connect repo → DNS records — is exactly right. Here it is in detail:

Step 1 — Create a GitHub repo

  1. Go to github.com → sign up / log in.
  2. Click New repository → name it e.g. atc-website → Create.
  3. Click uploading an existing file and drag in index.html and the assets folder (or push with Git if you prefer). Commit.

Step 2 — Deploy on Vercel

  1. Go to vercel.com → Sign up with GitHub.
  2. Click Add New → Project → import your atc-website repo → Deploy.
  3. In ~20 seconds you get a live link like atc-website.vercel.app. Your site is online (with free SSL).

Step 3 — Connect your Hostinger domain

  1. In Vercel: open your project → Settings → Domains → type your domain (e.g. adsthatconvert.co) → Add.
  2. Vercel shows you the DNS records to add. Usually: 
    A     @      76.76.21.21
CNAME www    cname.vercel-dns.com
    (Use the exact values Vercel shows you — they can change.)
  3. In Hostinger: Domains → DNS / Nameservers → Manage DNS records. Add the A record and the CNAME exactly as Vercel showed.
  4. Wait 10–60 minutes for DNS to update. Vercel will show ✅ Valid and auto-issue SSL. Done — your domain is live.
Every time you change the Settings block and push to GitHub, Vercel redeploys automatically in seconds. That's how you turn tools on/off later.

3 · Calendly booking

  1. Sign up at calendly.com → create an event type (e.g. 30-minute Strategy Call).
  2. Copy your event link — it looks like https://calendly.com/yourname/30min.
  3. Paste it into the Settings block: calendly: "https://calendly.com/yourname/30min".
Now every “Book a Call” / “Book a Strategy Call” button on the site opens your Calendly in a nice popup — no page leave. If you leave it empty, those buttons just open the contact form instead.

4 · Meta (Facebook) Pixel — how the code goes in most important for ads

You asked exactly how the pixel gets installed. Here's the full process:

Step 1 — Get your Pixel ID

  1. Go to Meta Events Manager.
  2. Click Connect data sources → Web → Meta Pixel → Connect. Name it “ATC”.
  3. You'll get a Pixel ID — a long number like 1234567890123456. Copy it.

Step 2 — Paste it (that's the “install”)

Put it in the Settings block: metaPixelId: "1234567890123456", save, and push to GitHub. Done. You do not paste any pixel <script> code yourself — the site already contains the official pixel code, and it activates the moment it sees your ID.

What it tracks automatically

  • PageView — fires on every page, so you can build audiences and run retargeting.
  • Lead — fires automatically the instant someone submits your contact form. This is the conversion event you optimize your ad campaigns for.

Step 3 — Verify it's working

  1. Install the free Meta Pixel Helper Chrome extension.
  2. Open your live site — the extension icon should show your pixel firing PageView.
  3. Submit a test form → it should show a Lead event. 🎉
Next level (later): Meta also offers the Conversions API for server-side tracking (more accurate, resists ad-blockers). We can add that once you're live and want to squeeze out more performance.

5 · Google Analytics 4

  1. Go to analytics.google.com → create an account + a GA4 property for your website.
  2. Under Data streams → Web, add your domain. You'll get a Measurement ID like G-XXXXXXXXXX.
  3. Paste it: ga4Id: "G-XXXXXXXXXX". Save + push.
Now you can see live visitors, traffic sources, top pages, and a generate_lead event every time a form is submitted.

9 · Your leads — where they go & email alerts

Already working: every form submission is saved to your Supabase project “ads that convert leadflow-crm”, in the table website_leads. Your existing data was not touched — this is a separate, clean table.

To view / export your leads

  1. Go to supabase.com/dashboard → your project → Table Editor → website_leads.
  2. Each row = one lead (name, agency, email, niche, ad spend, message, the page they came from, and UTM campaign tags).
  3. Click Export → CSV anytime to download them for your CRM or Excel.

Get an instant email alert on every new lead free · recommended

For low lead volume, the simplest 100% free way is Web3Forms — unlimited submissions, no account, no server, no monthly limit. The site is already wired for it; you just add a key:

  1. Go to web3forms.com → enter your email → they instantly email you an Access Key (no signup, no password).
  2. Paste it into the Settings block: web3formsKey: "your-access-key". Save + push.
Done. Now every lead is saved to Supabase (your record) and instantly emailed to you — which also pops up as a phone notification if you use the Gmail / Mail app. Zero cost, no limits at your volume.
